# قائمة التحقق اليدوي — Testimonials Spotlight v6

## 1. ظهور القسم والمحتوى
- [ ] افتح `/ar` -> تظهر أربعة بطاقات آراء باللغة العربية.
- [ ] افتح `/en` -> تظهر أربعة بطاقات آراء باللغة الإنجليزية.
- [ ] راجع البطاقتين الأولى والرابعة -> الشخص نفسه والنص متشابهان تقريباً.
- [ ] تحقق من ظهور النص والاسم والدور والأفاتار في كل بطاقة.

## 2. وضع سطح المكتب (Desktop)
- [ ] افتح الصفحة بعرض 721px -> يعمل وضع Desktop.
- [ ] مرّر خلال قسم الآراء -> تتحرك البطاقات أفقياً مع التمرير.
- [ ] راقب البطاقات المجاورة -> تظهر تأثيرات Scale وRotation وBlur.
- [ ] مرّر بين البطاقات -> تتغير النقطة النشطة حسب البطاقة الأقرب للتركيز.
- [ ] انقر على نقطة غير نشطة -> ينتقل التمرير بسلاسة إلى البطاقة المطلوبة.
- [ ] غيّر عرض النافذة إلى 1000px أو أقل -> يستمر عرض البطاقات بشكل صحيح.

## 3. وضع الهاتف (Mobile)
- [ ] افتح الصفحة بعرض 720px -> يعمل وضع Mobile.
- [ ] انتظر 4.5 ثوانٍ -> ينتقل العرض تلقائياً إلى البطاقة التالية.
- [ ] استمر في الانتظار -> يتكرر الانتقال التلقائي بين البطاقات.
- [ ] المس منطقة البطاقات -> يتوقف الانتقال التلقائي أثناء اللمس.
- [ ] ارفع إصبعك دون سحب -> يستأنف الانتقال التلقائي.
- [ ] اسحب أكثر من 40px -> ينتقل العرض إلى بطاقة أخرى.
- [ ] اسحب 40px أو أقل -> لا يتغير مؤشر البطاقة بسبب السحب.
- [ ] انقر على نقطة -> تظهر البطاقة المرتبطة بها ويتوقف autoplay لمدة 3 ثوانٍ.
- [ ] انتظر بعد النقر على النقطة 3 ثوانٍ -> يستأنف autoplay.

## 4. نقاط التنقل (Dots)
- [ ] افتح الصفحة دون Reduced Motion -> تظهر أربع نقاط تنقل.
- [ ] تحقق من النقاط -> لكل بطاقة نقطة واحدة.
- [ ] تحقق من تسميات النقاط -> تظهر بصيغة «الاقتباس رقم N».
- [ ] انتقل بين البطاقات -> تتغير النقطة النشطة وفق البطاقة المعروضة.

## 5. الحركة وإعدادات النظام
- [ ] فعّل prefers-reduced-motion: reduce -> لا ينفذ JavaScript أي حركة أو ينشئ نقاطاً.
- [ ] مع Reduced Motion -> تظهر البطاقات كشبكة ثابتة وفق CSS.

## 6. اتجاهات الصفحة (RTL / LTR)
- [ ] افتح `/ar` -> يعمل القسم ضمن اتجاه RTL.
- [ ] افتح `/en` -> يعمل القسم ضمن اتجاه LTR.
- [ ] اختبر التنقل في الاتجاهين -> تعمل البطاقات والنقاط دون أخطاء ظاهرة.
